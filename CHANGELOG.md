# Changelog

All notable public changes are documented here.

## 0.1.0 — Public preview

- Added the local node-based image workflow studio.
- Added Local Bridge and provider adapter boundaries.
- Added mock/fixture-based offline regression tests.
- Added deterministic motion atlas validation and exact cell splitting.
- Added GIF/APNG encoding with transparency handling.
- Added project persistence, result folders, portable backups, and workflow validation.
- Added public-release privacy scanning, security guidance, contribution docs, and multilingual README files.

This is an early public preview. Provider-backed generation remains opt-in and depends on the provider configuration supplied by each user.
