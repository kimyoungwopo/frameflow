# 작업 패널 개선 확인 — 2026-10-09

요청: 버튼이 떨어지거나 제목에 붙는 배치를 정리하고 패널의 텍스트를 줄인다.

변경한 경로: page.tsx의 작업 패널, globals.css의 패널 간격/컨트롤/상단 반응형 규칙,
workflow-edit-panel.tsx, workflow-plan-panel.tsx, workflow-tools-panel.tsx,
image-batch-panel.tsx, group-panel.tsx. 서버 요청, 인증, 실행 엔진은 변경하지 않았다.

자체 검토:

- 제목과 보조 버튼을 같은 행에 배치하고 16px 섹션 간격을 적용했다.
- 자연어 생성 폼을 빠른 작업 예시보다 먼저 표시한다. 빠른 작업은 펼쳐서 선택한다.
- 선택한 이미지 입력을 설정 탭 맨 위로 옮겼다. 기존 결과가 있을 때만 재조립 버튼을 표시한다.
- 반복 설명은 출력/적용/저장/그룹/수정 안내로 접었다. 수정안의 상세 단계도 접고 적용 버튼을 별도 행에 두었다.
- 긴 상태 메시지는 펼쳐 읽을 수 있으며 실행 중/오류 메시지는 그대로 표시한다.
- 패널 버튼·탭·셀렉트 트리거·즐겨찾기 버튼의 최소 높이는 44px다.
- 1001~1350px에서 상단 툴바를 두 행으로 배치해 버튼 글자가 쪼개지지 않는다.
- 기존 스타일 토큰과 DesignedSelect를 사용하며 새 의존성은 없다.

Chrome의 실제 앱에서 확인했다. 390px와 320px는 페이지 전체 캡처이고
데스크톱은 화면 캡처다. 최종 캡처는 마지막 CSS 수정과 빌드 반영 이후에 만들었다.
캡처 도구가 반환한 JPEG 바이트에 맞춰 파일 확장자를 .jpg로 정리했다.
모바일/태블릿/데스크톱 이미지를 직접 열어 제목 간격, 파일 이름 줄바꿈,
버튼 정렬과 텍스트 밀도를 확인했다. 임시 viewport는 원래 크기로 복원했다.

검증 중 AI 이미지 생성은 실행하지 않았다. 수정안 상세 패널의 배치는 소스/빌드와
기존 자연어 수정 회귀 테스트로 확인했으며 이번 UI 작업에서 새 GPT 수정안은 요청하지 않았다.
