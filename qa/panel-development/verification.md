# 패널 정리 및 기능 개발 검증

2026-10-08

## 변경

- 작업 만들기 / 입력·설정 / 템플릿 탭으로 패널을 나누었다. 동시에 보이는 패널은 하나다.
- 중복된 누끼 업로드, 현재 이미지 미리보기, 결과 보관함, 실행 로그와 알림 카드를 정리했다. 결과 관리는 결과물 화면에서 하고 실행 상태는 패널의 한 영역에 표시한다.
- 캔버스 위를 덮던 알림과 숨겨진 캔버스 명령 선택기 DOM을 제거했다.
- 공통 입력이 하나뿐이면 입력·설정 탭에서 바로 해당 사진 목록을 보여 준다. 후속 플로우를 만들거나 노드를 선택하면 설정 탭으로 이동한다.
- 기존 누끼 플로우 변환 버튼은 변환 가능한 예전 구조의 그룹에서만 보여 준다.
- 기본 select 요소를 모두 DesignedSelect로 교체했다. 선택 항목, 체크 표시, 설명, 포커스, 비활성 상태를 지원한다. portal로 메뉴를 렌더링해 스크롤 패널에 잘리지 않게 한다.
- 공통 스타일의 미적용 변경 사항을 표시한다. 생성된 스타일 프롬프트는 전용 설정 패널에서 변경하도록 캔버스의 직접 편집을 막았다.
- 결과 폴더 전체 또는 선택한 이미지를 ZIP으로 다운로드한다. 브라우저에서 기존 이미지 바이트로 ZIP을 만든다. 추가 AI 요청이나 외부 업로드는 필요 없다. 1~100장, 총 128MB 이하를 지원한다.
- 템플릿 이름 검색, 즐겨찾기 필터 및 즐겨찾기 우선 정렬을 추가했다. 즐겨찾기는 템플릿 메타데이터와 함께 브라우저에 저장한다.

## 검증

- 최종 `npm run build --prefix web`: 성공, TypeScript 검사 포함.
- 최종 `node --test --test-reporter=dot tests/*.test.cjs bridge/tests/*.test.js`: 93개 통과, exit 0. 빌드 중 생성 파일을 읽는 기존 시작 테스트와 충돌한 검증은 빌드 완료 후 순서대로 다시 수행했다. 테스트 코드는 약화하지 않았다.
- 모든 TSX에서 `<select` 검색 결과 없음. 실제 DOM에서도 기본 select는 0개다.
- 세 패널 각각을 320 / 390 / 768 / 1280px에서 캡처했다. 12개 상태 모두 문서 너비가 뷰포트 너비와 같고, 보이는 tabpanel은 하나이며, 덮는 알림 요소는 없다.
- 키보드 Home / 방향키 / Enter로 배경 선택을 변경하고 미적용 변경 표시를 확인했다. Escape로 메뉴를 닫으면 combobox로 포커스가 돌아온다.
- 390px 출력 방식 메뉴 경계: left 31, right 359, top 450.09, bottom 591.69. 화면 안에 표시되었다.
- 390px 결과 후속 작업 메뉴 경계: left 31, right 359, top 450, bottom 655.39. 화면 안에 표시되었다.
- 템플릿 즐겨찾기 설정, 이름 검색, 즐겨찾기 필터를 실제 조작했다. 새로고침 후 즐겨찾기의 aria-pressed=true를 확인했다.
- 선택된 결과 2장 ZIP과 폴더 전체 3장 ZIP을 실제 다운로드했다. Python zipfile로 두 파일 모두 CRC 오류가 없음을 확인했다. 전체 ZIP의 이미지 바이트 해시가 예제 백업의 원본 세 파일과 일치했다.
- 결과 후속 작업의 디자인 선택 메뉴에서 광고 연출을 선택하고 새 그룹 생성 및 설정 탭 자동 이동을 확인했다.
- 별도 검증 탭에서 콘솔 error 목록이 비어 있음을 확인했다.
- 기존 공개 링크 페이지 HTTP 200. Bridge PID 68288과 기존 터널은 유지했다. 웹 프로세스만 교체했다.

## 근거 파일

- `final-panel.png`: 최종 패널과 디자인된 출력 선택 메뉴.
- `select-mobile.png`, `results-mobile.png`: 모바일 선택 메뉴.
- `create-*`, `configure-*`, `library-*`: 세 패널의 네 가지 화면 너비 캡처.
- `results-desktop.png`: 결과 선택과 묶음 다운로드 진입점.
- `template-favorite.png`: 템플릿 즐겨찾기 및 검색 조작 상태.
- `selected-results.zip`: 실제 내려받은 선택 결과 두 장.
- `folder-results.zip`: 실제 내려받은 폴더 전체 세 장.

ZIP 검증에 사용한 제품 사진과 예제 결과 폴더는 기존 데모 자산이다. AI 생성 품질을 평가하기 위한 검증은 아니다. 기존 다크 테마와 캔버스 이동 방식을 유지했다.

## 자체 검토

- 새 의존성을 추가하지 않았다. 선택 메뉴를 하나의 컴포넌트로 공유한다.
- 메뉴는 외부 클릭, Escape, Tab, 화면 크기 변경과 패널 스크롤에서 닫히며 자체 메뉴 스크롤은 유지된다.
- ZIP은 원본 픽셀과 투명도를 다시 인코딩하지 않는다. 한글 파일명을 UTF-8로 기록하고 번호로 같은 이름의 충돌을 방지한다.
- 기존 템플릿에 즐겨찾기 필드가 없어도 정상적으로 읽는다. 잘못된 타입은 거부한다.
- 캔버스나 프로젝트 구조를 지우지 않고 기능을 추가했다. 계정 연결과 Bridge 동작은 변경하지 않았다.
