# Frameflow Agent State

이 디렉터리는 프로젝트 에이전트의 durable state다. 규칙은 `/AGENTS.md`, 작업 범위는 `작업/`, 결정은 `생각/`, 미래 후보는 `아이디어/`, 진행 상태는 `진행중/`, 증거가 있는 완료는 `완료/`에 둔다.

## 사용 순서

```bash
npm run agent:check
```

작업을 시작할 때 관련 문서를 읽고, 범위를 `docs/작업/`에 기록한다. 구현 중에는 `docs/진행중/`에 blocker와 다음 검증을 기록한다. 실제 테스트·브라우저·외부 상태 확인이 끝난 뒤에만 `docs/완료/`에 evidence를 남긴다.

## 기록 원칙

- 파일명은 주제 중심으로 작성한다.
- 완료 문서에는 정확한 명령어, URL 또는 artifact 경로를 기록한다.
- 추정·미확인·provider 인증 부재는 성공으로 기록하지 않는다.
- 인증 정보, API 키, 토큰, 비밀번호, 연결 문자열은 기록하지 않는다. 필요하면 `[REDACTED]`를 쓴다.
