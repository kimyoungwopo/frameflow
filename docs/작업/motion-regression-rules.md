# Motion 재발 방지 규칙

## 확정된 실패 원인

provider가 눈과 앞발을 잘못 생성했을 때 원본 눈 영역을 잘라 provider 프레임 위에 덧씌우는 임의 보정을 수행했다. 결과는 시각적으로 나아 보여도 Frameflow의 provider/MOTION 결과가 아니며, 원본 raster 보존 규칙을 우회한다.

## 금지

- provider 프레임 위에 원본 얼굴·눈·앞발 patch를 합성하지 않는다.
- 눈·귀·앞발을 수동 도형, SVG, ImageDraw, crop 복원으로 고치지 않는다.
- 임의로 정렬한 원본 조각을 provider 결과로 표시하지 않는다.

## 실패 게이트

다음 중 하나라도 있으면 해당 프레임과 motion 실행을 실패 처리한다.

- 눈 개수·형태·좌우 균형이 원본과 다름
- 앞발·다리·꼬리 등 신체 구조가 깨짐
- provider가 한 프레임에 여러 자세·잔상·중복 신체를 생성함
- 원본 raster 스타일이 벡터풍으로 변함

실패 시 허용되는 후속 동작은 provider/MOTION 재생성 또는 사용자에게 중단 보고뿐이다. 로컬 합성으로 성공처럼 만들지 않는다.

## 표시 규칙

실제 provider/MOTION 출력과 로컬 인코더 검증본을 구분한다. provider 프레임이 위 게이트를 통과하기 전에는 GIF를 사용자 결과물로 보내지 않는다.
