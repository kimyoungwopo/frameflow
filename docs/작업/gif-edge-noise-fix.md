# GIF 경계 노이즈 수정

## 범위
- 브라우저 GIF 인코더의 프레임별 팔레트 변동과 반투명 경계 처리를 수정한다.
- provider 호출 없이 로컬 인코더 구조와 기존 테스트·빌드로 검증한다.

## 수용 기준
- 모든 GIF 프레임이 하나의 공통 팔레트를 사용한다.
- 반투명 픽셀은 GIF 호환 이진 알파로 정규화하고 투명 픽셀의 RGB 잔여값을 제거한다.
- 기존 FPS·무한 반복·프레임 수 계약을 유지한다.
- typecheck, 관련 테스트, build, agent:check가 통과한다.
- 실제 provider 결과는 비용 발생 가능성 때문에 실행하지 않으며, 로컬 인코더 호출 검증 범위와 분리해 보고한다.
